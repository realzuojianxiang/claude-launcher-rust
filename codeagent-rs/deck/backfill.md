# 待你回填的真料清单

> 这份清单只收 **只有你知道、我不能编** 的料。
> 凡 PPT 里 `{TODO: ...}` 出现的位置，对应这里的一项。
> 每项标了「为什么投资人会问」+「建议口径」，回填时直接把真料/选项给我即可。

---

## 一、主题页一句话钩子

**当前占位**：「让企业把 AI 写代码的能力，留在自己的机房里。」

**为什么问**：主题句是 30 秒内能不能抓住投资人。你愿意用这句，还是想用更偏你口径的一句？

**建议**：保留或改。给一句你自己的也行。

---

## 二、竞品表（在生态中的位置页）

**你已选**：闭源 SaaS 派为你心里主力名单。

**为什么问**：投资人看你与谁贴着打 = 你的格局感。当前 PPT 的四档分类我替你拟了，但「是否各派都有具体家被列好」「你心里的竞品名单长度」只有你知道。

**建议口径**：

- 当前四派是我帮你拟的（闭源 SaaS / 开源自主可控 / 大厂企业版 / 我们），你心里若有更贴的同台对手，点名我替换。
- 特别是「大厂企业版编程助手」这一档（通义 / 百度 Comate / 华为云等），**它们才是你真正的同台对手**，名单需你确认。
- 想在讲的时候哪几派略过、哪几派重点，告诉我，我改详略。

**需你回填**：你心里的竞品名单（尤其是企业级那一档）。

---

## 三、市场规模（TAM / SAM / SOM）

**为什么不能编**：投资人追问「这个 TAM 怎么算的」时，「我查的」终会被薄。但种子轮对数字本身可弱，对**可溯源**强。

**建议口径**：

- 你给一个最你认账的 TAM + 出处（哪怕「据 XX 报告 2024」），SAM / SOM 我可以据你给的比例帮你推算并标「估算」。
- 若你一时没有，我建议把这一页**降级为「市场量级 + 趋势」定性图**，不出现具体数字，只讲「这是百亿级 + 在快速增长」这种投资人能接受的方向感陈述。

**需你回填**：要么几个带出处的数字，要么选择「改定性陈述」让我重写这页。

---

## 四、商业模式（种子轮方向感）

**为什么问**：种子轮不需要完整单位经济，但需要你定下**主航道**。否则投资人问「你到底卖什么」时你给不出方向。

**当前 PPT 候选**：私有部署费 / 按席位订阅 / 模型对接集成服务 / 平台演进

**需你回填**：你倾向的主线（一条为主可以 + 提一句长期）。我据你主线把这页重写为「主航道 + 长期」结构。

---

## 五、团队（路演重头）

**为什么不能编**：团队是种子轮的命根。投资人投种子轮实质是投人。

**当前 PPT**：占位 `{TODO: 姓名}` / 角色 / 背景信用。

**需你回填**：

- 你的姓名、角色、主导方向
- **一条给投资人听的信用背景**：过往职务 / 重要项目 / 已交付 / 业内信用 / 合作资源 ——越具体越好
- 其他核心成员（若有），或「团队正在补全」（明说）也比占位真实

> 不能公开的全名 → 给我一个投资人能站住的脱敏口径（如「资深 X 背景，主导过 Y 类项目」），我据此润色。

---

## 六、融资条款

**为什么问**：种子轮常被问「要多少、花哪、能到什么里程碑」。

**需你回填**：

- 本轮金额（人民币）
- 四块占比（研发 / 客户对接 / 团队 / 储备）
- 12-18 个月关键里程碑（1-3 个）
- 估值期待（或留「希望共同厘定」）

**建议**：若你给不了金额粒度，先给「用途比例 + 里程碑」，金额可以「面议口径」占位，种子轮这样合格。

---

## 给我的回填格式（最高效）

把这份回填贴回来即可，不必都填满，缺的留空：

```
一句话钩子: <或保留>
竞品名单: <或保留我的>
市场数字: <或选「改定性陈述」>
商业模式主线: <挑一条为主>
团队真料: <姓名/角色/背景>
融资金额 / 占比 / 里程碑 / 估值: <能给多少给多少>
```

收到回填，我把五页润色贴合你的事实口径，并相应清理 `{TODO}` 占位 — 一轮成型。
